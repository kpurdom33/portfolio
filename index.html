Food Logger

Log food in everyday language. See calories and protein update with your portion.

Enter a food and quantity, check the matched food, and add it to your daily log. The app handles name variations and supported serving units using a curated database that includes USDA nutrition data.

  • Python
  • pandas
  • Streamlit
  • RapidFuzz
  • Regex
  • USDA data
View live app ↗ View code ↗

How I built it

01

The problem

Food names, nutrition records, and serving sizes don't follow one format. A useful log needs to turn those inconsistent inputs into comparable amounts.

02

The approach

I built a Python workflow to clean USDA records and prepare food-specific portions. The app parses quantities with regex, matches names with RapidFuzz, and converts supported units into grams.

03

Making it reliable

Uncertain matches ask for confirmation. Unsupported units block saving. Automated tests cover portion calculations, manual entries, and separate visitor demo logs.
